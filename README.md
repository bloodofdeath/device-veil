# Device Veil

Браузерное расширение (Manifest V3) для Chrome, Edge и Firefox, снижающее точность пассивного и активного цифрового отпечатка устройства.

## Возможности

- **Стандартизация платформы и оборудования**: подмена `navigator.platform`, `hardwareConcurrency`, `deviceMemory`, `maxTouchPoints`, `screen.colorDepth` / `pixelDepth`, а также User-Agent Client Hints (`navigator.userAgentData` и `getHighEntropyValues` только для запрошенных полей).
- **Обобщение GPU в WebGL / WebGL2**: перехват `VENDOR`, `RENDERER`, а также `WEBGL_debug_renderer_info` (`UNMASKED_VENDOR_WEBGL` и `UNMASKED_RENDERER_WEBGL`).
- **Защита во всех фреймах**: скрипты запускаются на `document_start` с `all_frames: true`.
- **Исключения для сайтов**: быстрая пауза и включение защиты для текущего домена прямо из popup.
- **Раздельные модули**: можно независимо включать или отключать маскировку Navigator/Client Hints и WebGL.
- **Без DOM-маркеров и телеметрии**: расширение не добавляет служебные атрибуты в DOM и не отправляет данные на внешние серверы.

## Установка для разработки

### Chrome / Edge
1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку проекта.

### Firefox
1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение**.
3. Выберите файл `manifest.json` из папки проекта.

> В Firefox временное дополнение нужно загружать заново после перезапуска браузера.

## Проверка и тесты


## Важно

Это не VPN и не шифрование. Расширение не меняет IP-адрес, не скрывает сетевые параметры соединения и не гарантирует полную анонимность. Оно стандартизирует только часть JavaScript API, доступных странице. Если на конкретном сайте возникают проблемы с совместимостью, поставьте защиту на паузу для этого домена в popup и обновите вкладку.
